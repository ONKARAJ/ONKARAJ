## 🚀 Featured Projects

### 🤖 Conversational AI RAG Chatbot

[![GitHub](https://img.shields.io/badge/View_on_GitHub-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ONKARAJ/conversational-ai-rag-chatbot)

A full-stack conversational AI application combining RAG, semantic search, and persistent conversation memory.

- 🧠 Built RAG pipelines using LangChain and ChromaDB for context-aware responses.
- 🔍 Implemented semantic search and vector-based document retrieval.
- 💬 Added session-based persistent conversation memory using SQLite.
- ⚡ Integrated Groq-hosted LLMs for AI-generated responses.
- 📊 Used LangSmith for LLM tracing and observability.
- 🚀 Developed a React frontend and FastAPI backend, deployed on Render.

**Tech Stack:** Python, LangChain, Groq, FastAPI, React.js, ChromaDB, SQLite, LangSmith
